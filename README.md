# Employee-Turnover-Analytics

This project analyzes employee turnover using data science techniques, focusing on key workplace factors such as job satisfaction, workload, salary, and promotions. The goal is to understand employee retention patterns through **EDA, clustering, classification models, and risk segmentation**.

## Steps Performed  

### 🔹 Data Preprocessing  
- Checked for missing values and cleaned the dataset.  
- Encoded categorical variables and handled class imbalance using **SMOTE**.  
- Feature engineering (combining satisfaction, evaluation, and workload).  

### 🔹 Exploratory Data Analysis (EDA)  
- Box plots, histograms, and **correlation heatmaps** to explore key features.  
- Distribution analysis of **satisfaction levels, evaluation scores, and working hours**.  
- Project count comparison between employees who left vs. stayed.  

### 🔹 Clustering & Hypothesis Testing  
- **K-Means Clustering** to segment employees based on satisfaction and evaluation.  
- Identified high-risk employee groups based on performance and workload.  

### 🔹 Model Training & Evaluation  
- Trained **Logistic Regression, Random Forest, and Gradient Boosting** models.  
- Applied **5-fold cross-validation** for performance comparison.  
- Evaluated models using **Precision, Recall, F1-score, and ROC-AUC**.
